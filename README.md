Streamlit으로 만든 턴제 전략 게임입니다.

게임 목표

적군의 본진을 점령하거나 모든 적군을 처치하면 승리합니다.

주요 기능

8×8 전략 맵

보병 / 궁수 / 기사

이동 및 전투

도시 점령

골드 경제 시스템

유닛 생산

AI 적군

턴제 게임 진행

Streamlit 기반 웹 플레이

실행
pip install -r requirements.txt
streamlit run app.py


브라우저에서 표시되는 주소로 접속하면 게임을 플레이할 수 있습니다.

배포

GitHub 저장소에 app.py와 requirements.txt를 올린 뒤 Streamlit Community Cloud에서 저장소와 app.py를 선택하여 배포합니다.
